# 종이접기 챔피언

종이를 **마음대로** 접어 만든 비행기·배·자동차를 고무줄 동력으로 움직여 기록을 겨루는 웹 게임입니다.
정해진 모델이 없습니다. 접힌 모양 그대로 무게중심·면적·대칭을 계산해 물리 시뮬레이션에 넣습니다.

## 실행

설치나 빌드가 필요 없습니다. `index.html` 을 브라우저로 열면 됩니다 (PC·모바일 모두 지원).

```
python3 -m http.server 8000   # 선택: 로컬 서버로 열기 → http://localhost:8000
```

## 게임 방법

1. **접기** – 종이의 아무 곳이나 잡아 끌면 그 자리에서 접힙니다. 모서리·변의 중점·접은 자국에는 자석처럼 붙습니다.
   - `↩ 되돌리기`, `🔄 뒤집기`, `📄 윗장만`(맨 위 장만 접기), `〰 접었다 펴기`(기준선 만들기), `🧲 자석`(모서리에 붙기 켜고 끄기), `✅ 완성`
   - 비행기 날개: 반으로 접은 뒤 `📄 윗장만`을 켜고 한쪽 날개를 접고, `🔄 뒤집기` 후 반대쪽도 접습니다. 날릴 때 날개는 자동으로 90° 펴집니다.
   - 처음이라면 "도안 보며 접기"로 시작해도 되고, 중간부터 마음대로 바꿔도 됩니다.
   - 완성하면 모양을 분석해 장단점을 알려 줍니다.
2. **움직이기** (모두 고무줄 동력, 모든 선수가 같은 코스)
   - ✈️ 비행기: 고무줄 새총을 뒤로 당겼다 놓습니다. 각도와 세기가 전부입니다. (비행 거리 / 체공 시간)
   - ⛵ 배: 아래로 당겨 고무줄 물레방아를 감았다 놓고, 손가락으로 키를 잡습니다. (항해 거리 / 버틴 시간)
   - 🚗 자동차: 뒤로 당겨 감았다 놓습니다. 꾹 누르면 고무줄을 잡아 아낍니다. (주행 거리 / 최고 속도)
3. **순위표** – 기록은 선수 이름과 함께 이 기기의 브라우저(localStorage)에 저장됩니다.

## 물리

| 섹션 | 접힌 모양에서 계산하는 것 | 결과 |
| --- | --- | --- |
| 비행기 | 날개 면적/질량, 가로세로비, 공력중심과 무게중심의 거리, 피치 관성, 좌우 대칭 | 양력·항력·실속, 피치 안정(뒤가 무거우면 뒤집힘), 비대칭이면 선회 |
| 배 | 길이/폭, 뱃머리 뭉툭함, 폭 방향 2차 모멘트, 평균 겹 수 | 조파 저항, 횡요 복원력(좁으면 흔들려 물이 넘어옴), 젖는 속도 |
| 자동차 | 옆모습의 높이·앞면 뭉툭함, 무게중심 높이, 관성, 겹 수 | 2D 강체 + 스프링 접촉 바퀴, 공기·구름 저항, 높으면 전복 |

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/fold.js` | 종이접기 엔진(겹 단위 다각형 반사), 자유 접기 화면, 모양 분석 `G.analyze` |
| `js/plane.js` `js/boat.js` `js/car.js` | 모양 → 물리 계수(`G.PHYS.*`)와 각 섹션 시뮬레이션 |
| `js/audio.js` | Web Audio 합성 효과음 (프로펠러·바람, 뱃고동·물레방아, 엔진, 종이 소리) |
| `js/models.js` | 섹션 정의와 따라 접기 도안 |
| `js/main.js` | 화면 전환, 보관함, 순위표, 게임 루프 |
