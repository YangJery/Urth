# 종이접기 챔피언

종이를 직접 접어 만든 비행기·배·자동차를 실제로 움직여 기록을 겨루는 웹 게임입니다.

## 실행

설치나 빌드가 필요 없습니다. `index.html` 을 브라우저로 열면 됩니다 (PC·모바일 모두 지원).

```
python3 -m http.server 8000   # 선택: 로컬 서버로 열기 → http://localhost:8000
```

## 게임 방법

1. **접기** – 색종이와 모델을 고르고, 빨간 점을 잡아 점선 동그라미까지 끌어다 놓으면 접힙니다.
   반듯하게 접을수록 정밀도(S~C 등급)가 높아지고 성능이 좋아집니다.
2. **움직이기**
   - ✈️ 비행기: 화면을 뒤로 당겼다 놓아 던지고, 꾹 눌러 기수를 듭니다. 상승 기류를 타면 더 멀리 갑니다. (비행 거리 / 체공 시간)
   - ⛵ 배: 손가락을 따라 배가 움직입니다. 바위와 소용돌이를 피하고 ☀️로 말리세요. (항해 거리 / 버틴 시간)
   - 🚗 자동차: 꾹 누르면 태엽이 풀리며 달립니다. 오르막에서만 써서 아끼고 고무줄로 충전하세요. (주행 거리 / 최고 속도)
3. **순위표** – 기록은 선수 이름과 함께 브라우저(localStorage)에 저장되어 섹션·종목별 순위가 매겨집니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/models.js` | 섹션·모델(접는 순서, 성능) 정의와 완성품 그림 |
| `js/fold.js` | 종이접기 엔진(겹 단위 다각형 반사)과 접기 화면 |
| `js/plane.js` `js/boat.js` `js/car.js` | 각 섹션의 물리 시뮬레이션 |
| `js/main.js` | 화면 전환, 보관함, 순위표, 게임 루프 |

새 모델은 `js/models.js` 의 `steps`(접는 선 + 잡는 점)와 `phys` 값을 추가하면 됩니다.
